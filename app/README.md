# Assisty — Flutter app (placeholder)

This folder is a placeholder. The Flutter app is scaffolded in a later phase.

Planned stack:
- **Flutter** with **Riverpod 2** for state management
- **supabase_flutter** for auth + data access
- **FCM** (Firebase Cloud Messaging) for push notifications

For now, all active development lives in [`../backend`](../backend) (the NestJS
monolith) and [`../supabase`](../supabase) (SQL migrations). See the root
[README](../README.md) and [docs/DEPLOY.md](../docs/DEPLOY.md) to run the
backend locally.
